ROYAL SWEETS WEBSITE
====================
Chalane ke liye: index.html ko double-click karke browser mein kholiye.
(Fonts internet se aate hain, isliye internet chalu rakhein.)

Files
-----
index.html     -> page ka content
css/style.css  -> design, colors, animations
js/main.js     -> menu, cart, WhatsApp order, cursor, animations
images/        -> menu, hero aur gallery ki photos (webp)

Zaroori badlav
--------------
1. WhatsApp number: js/main.js mein PHONE (abhi 919672244908) aur index.html mein
   "919672244908" search karke badal sakte hain.
2. Photo badalna: images/ mein usi naam se nayi photo daal dein (ya js/main.js ke PRODUCTS mein img path badlein).
3. Prices: PRODUCTS mein price (per kg) abhi andaaza hain – apne rate daalein.
4. Dukaan ka pata aur timing: index.html mein "Contact" section.
5. Social media links: index.html ke footer mein href="#" ki jagah apne
   Instagram / Facebook / YouTube ke links daalein.
6. Colors: css/style.css ke top mein :root ke variables.

Hosting: poore folder ko Netlify, GitHub Pages ya kisi bhi hosting par upload kar dein.
